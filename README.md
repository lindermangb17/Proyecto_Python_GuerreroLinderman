# Proyecto_Python_GuerreroLinderman
Desarrollo del proyecto de python, con temática Gestor de Diagnóstico Clínico – ACME Clinic. Realizado por Linderman Guerrero Ballesteros 

Se realizó un sistema de gestión clínica desarrollado en Python que permite registrar usuarios y pacientes, realizar diagnósticos, consultar historias clínicas y generar prescripciones en archivos JSON.

Funcionalidades
- Inicio de sesión y permisos por rol.
- Registro de usuarios y pacientes.
- Diagnósticos y prescripciones médicas.
- Consulta de historias clínicas.
